# AI-Психолог (Groq Edition)

AI-Психолог — это веб-приложение на Python, которое помогает проанализировать эмоциональное состояние человека на основе его текста. Приложение определяет основную эмоцию, анализирует характер мыслей, оценивает интенсивность разных чувств и предлагает рекомендации, которые могут помочь лучше понять своё состояние.

Изначально проект использовал библиотеку g4f, однако из-за нестабильной работы и частых ошибок я решил перейти на официальный Groq API с моделью openai/gpt-oss-120b. Также я добавил параллельную обработку запросов, чтобы сократить время ожидания, и реализовал защиту от Prompt Injection — попыток повлиять на поведение модели с помощью специально составленного текста.

## Основные возможности

Приложение определяет главную эмоцию пользователя, например радость, тревогу, грусть или гнев, и кратко описывает её. Кроме того, оно анализирует мысли, выделяя такие особенности, как позитивное мышление, тревожность, чрезмерные опасения и самокритика.

Для более наглядного результата приложение оценивает интенсивность шести эмоций: радости, грусти, злости, страха, удивления и тоски. Каждой эмоции присваивается значение от 0 до 100, после чего результаты отображаются на столбчатой диаграмме.

На основе полученного анализа приложение формирует краткую рекомендацию и подбирает музыкальный трек, который может соответствовать текущему настроению пользователя.

Чтобы ускорить обработку, несколько задач выполняются параллельно с помощью ThreadPoolExecutor из библиотеки concurrent.futures. Это позволяет одновременно получать результаты анализа эмоций, характера мыслей и рекомендаций, а также строить график, не ожидая завершения каждой операции по отдельности.

## Защита от Prompt Injection

Поскольку пользователь может ввести произвольный текст, приложение использует несколько механизмов защиты от попыток манипулировать ответами искусственного интеллекта.

Первый уровень защиты реализован на уровне промптов. Пользовательский текст помещается внутрь тегов <text_to_analyze>, а системные инструкции указывают модели, что содержимое этих тегов является данными для анализа, а не командами. Это помогает снизить вероятность выполнения инструкций, которые пытаются изменить роль модели, сбросить предыдущие указания или искусственно повлиять на результаты анализа эмоций.

Второй уровень защиты находится в файле graph.py. Функция sanitize_emotions_data проверяет полученные значения эмоций и обрабатывает некоторые подозрительные результаты. Например, если модель возвращает максимальное значение для одной эмоции и нулевые значения для остальных, программа может заменить такой результат более правдоподобным набором значений, соответствующим предусмотренному сценарию обработки.

Эти механизмы помогают уменьшить влияние некорректного пользовательского ввода, однако не гарантируют полной защиты от всех видов Prompt Injection.

## Структура проекта

Основная логика приложения разделена на несколько файлов. В app.py находится Flask-сервер, обработка маршрутов и запуск параллельных задач. Файл emotions.py отвечает за определение преобладающей эмоции, а thinking.py анализирует характер мыслей пользователя. В graph.py реализованы оценка интенсивности шести эмоций, проверка полученных значений и создание диаграммы. Файл recommendations.py отвечает за генерацию рекомендаций и подбор музыки.

В папке templates находится файл index.html, который определяет внешний вид страницы, форму ввода и отображение результатов. В папке static сохраняется изображение emotion_graph.png с результатами анализа эмоций. Файл .env используется для хранения API-ключа Groq, а .gitignore предотвращает добавление секретных и служебных файлов в Git. В requirements.txt перечислены библиотеки, необходимые для запуска приложения.

## Используемые технологии и зависимости

Проект разработан на Python. Для создания веб-приложения используется Flask, для взаимодействия с искусственным интеллектом — официальный клиент Groq, а для построения графиков — Matplotlib. Библиотека python-dotenv позволяет загружать переменные окружения из файла .env.

Для установки зависимостей используется файл requirements.txt со следующим содержимым:

flask
groq
matplotlib
python-dotenv

Библиотека concurrent.futures входит в стандартную библиотеку Python, поэтому устанавливать её отдельно не нужно.

## Установка и запуск

Для начала необходимо скачать или клонировать репозиторий проекта и открыть его корневую папку в терминале. Рекомендуется создать виртуальное окружение, чтобы зависимости проекта не конфликтовали с другими установленными библиотеками.

Для создания виртуального окружения выполните команду:

python -m venv venv

На Windows активируйте его командой:

venv\Scripts\activate

На Linux или macOS используйте:

source venv/bin/activate

После активации виртуального окружения установите необходимые библиотеки:

pip install -r requirements.txt

Затем создайте файл .env в корневой папке проекта и добавьте в него свой API-ключ Groq в следующем формате:

GROQ_API_KEY=ваш_ключ_groq

Вместо текста «ваш_ключ_groq» необходимо указать действительный ключ API. Не публикуйте его в открытом доступе и не добавляйте файл .env в репозиторий. Он уже предусмотрен в .gitignore.

После настройки окружения запустите приложение командой:

python app.py

Когда сервер запустится, откройте браузер и перейдите по адресу http://127.0.0.1:5000. На странице можно будет ввести текст и получить результаты анализа.

## Возможные ошибки

Если при обращении к Groq появляется ошибка AuthenticationError, проверьте правильность API-ключа, наличие переменной GROQ_API_KEY в файле .env и корректную загрузку переменных окружения с помощью python-dotenv. Также убедитесь, что ключ действителен и доступ к API работает.

Если график не создаётся или возникают ошибки Matplotlib при работе сервера, проверьте настройку графического бэкенда в файле graph.py. Для серверной генерации изображений используется неинтерактивный бэкенд Agg, который необходимо активировать до импорта matplotlib.pyplot. Это позволяет создавать графики без открытия отдельных окон и подходит для работы в фоновых потоках.
