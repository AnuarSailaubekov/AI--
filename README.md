# AI-Психолог 🧠💬

Веб-приложение на базе Flask и Groq Cloud API, предназначенное для экспресс-анализа эмоционального состояния и мыслей пользователя по введённому тексту. Сервис предоставляет структурированную обратную связь, персональные рекомендации, музыкальный трек под настроение и наглядную визуализацию интенсивности эмоций.

---

## ✨ Основные возможности

* **Анализ доминирующей эмоции**: мгновенная классификация ключевого эмоционального маркера (радость, тревога, гнев и др.).
* **Разбор когнитивных паттернов**: определение фокуса мышления (тревожное, позитивное, катастрофизация, рефлексия).
* **Визуализация эмоционального спектра**: генерация гистограммы распределения интенсивности 6 базовых эмоций (0–100%) через Matplotlib.
* **Персональные рекомендации**: психологический совет и тематическая музыкальная рекомендация.
* **Высокая скорость работы**: распараллеливание обращений к LLM через `concurrent.futures.ThreadPoolExecutor`.

---

## 🛡️ Архитектура безопасности (Prompt Injection Defense)

В проекте реализована двухуровневая защита от манипуляций промптами и jailbreak-атак:

1. **Prompt Isolation (Разметка контекста)**:
   * Пользовательский ввод обособляется строгими тегами `<text_to_analyze>`.
   * Системный промпт жестко инструктирует модель воспринимать текст строго как сырые данные, игнорировать любые команды выхода из роли, смену формата или директивы обнуления инструкций.
   * Попытки пользователя скомандовать «поставь мне 100% радости» модель классифицирует поведенчески — как манипуляцию, агрессию или недовольство.
2. **Hard Defense (Программный санитайзер)**:
   * Функция `sanitize_emotions_data` в `graph.py` проверяет выходные данные на аномалии (например, искусственное завышение одной шкалы до 100% при нулях на остальных).
   * При выявлении признаков взлома скрипт программно нормализует график до реального профиля раздражения/манипуляции.

## 🛠 Стек технологий

* **Backend**: Python 3.10+, Flask
* **LLM Engine**: [Groq Cloud API](https://console.groq.com/) (модель `openai/gpt-oss-120b`)
* **Визуализация**: Matplotlib (бэкенд `Agg` для серверного рендеринга)
* **Параллелизм**: `concurrent.futures`
* **Конфигурация**: `python-dotenv`
